A read-only review for the end of a phase of work, before a PR is opened. It asks two questions an ordinary code review does not: **what did I decide without asking**, and **where did the design acquire tension it does not need**. The output is a short report and a `Decide these` list, never an edit — half the findings are stale prose, and rewriting the sentence resolves the symptom while destroying the evidence that a decision went unreviewed.

The review scales. The commit range sets a floor: a phase that changed behaviour without moving a rule that governs it, or that wrote the rules it is now being checked against, starts deeper. Only an explicit ask — "be critical", or questioning a design choice you made yourself — promotes it to putting the architecture document itself on the table, where each strained rule has to re-earn its place against what dropping it would actually buy.

Six checks run at every depth: prose that contradicts the code, escalation language that signals a seam or a bad description of one, `foundational` rules nothing would catch, new public surface, standing prohibitions, and document weight. A finding has to name what goes wrong if it is left alone — a sentence that would lead someone to write the wrong code, not one that could be phrased better — so the review protects the code and the author's decisions rather than polishing the documents. Where a project tiers its rules — see `set-foundation` — the review reads those tiers to decide what is open for challenge, reports promotions and demotions back, and searches for new violations of the `foundational` rules marked vigilant, which is where a real bug ships with every test green. Anything real the phase will not fix is proposed in a `File these` list, as issues or as fallback entries, for the author to approve; the review opens nothing itself. A hand-kept roadmap is checked against the tracker in both directions — a listed issue that has closed, and an open question the roadmap has dropped — since a copy of tracker data is only safe while something compares it.
